# Java Çalışmaları

Java ile geliştirdiğim konsol projeleri ve nesne yönelimli programlama çalışmalarım.

## Projeler

| Proje | Açıklama |
| --- | --- |
| [Araba Takip Sistemi](Araba_Takip_Sistemi/) | Araçların kilometre, bakım geçmişi ve bakım masraflarını takip eden konsol uygulaması. |
| [Araç Hizmet Sistemi](Arac_Hizmet_Sistemi/) | Araç ve kişi sınıfları üzerinden kalıtım, soyut sınıflar ve çok biçimlilik çalışması. |

Her projenin özellikleri ve çalıştırma bilgileri kendi klasöründeki README dosyasında bulunur.

## Kullanılan Konular

- Sınıflar, nesneler ve kapsülleme
- Kalıtım, soyut sınıflar ve metot ezme
- Diziler ve koleksiyonlar
- Hata yakalama ve veri doğrulama

## Çalıştırma

Java geliştirme kiti (JDK) kurulu bir ortamda ilgili projeyi IDE ile açın. Her proje bağımsız çalışır; kaynak dosyalarını tek bir paket altında birleştirmeyin.
